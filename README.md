# Customer Churn Prediction & Analysis 📉

A Python-based data science project aimed at analyzing customer behavior, identifying key churn risk factors, and predicting customer retention.

The repository contains the following files:

*   **`churn_analysis.py`**: The core Python script responsible for data processing, statistical exploration, and predictive modeling[cite: 4].
*   **`customer_churn.csv`**: The dataset containing customer demographic details, account usage information, and churn status labels[cite: 4].

## 🚀 Features

*   **Exploratory Data Analysis (EDA)**: Investigates customer patterns to discover why clients choose to leave or stay.
*   **Machine Learning Pipeline**: Automated script execution for data preparation, feature engineering, and churn classification[cite: 4].
